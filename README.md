# Finance Dashboard

Analysis of a large financial transactions dataset (250,000 rows, Jan 2021 - Jun 2026) built with Python, and an interactive Streamlit dashboard on top of it.

The data covers income and expense transactions across 19 categories, 8 accounts, 10 cities and 50 merchants. The Jupyter notebook does the loading, cleaning, aggregation and analysis. `app.py` turns the same data into a filterable dashboard.

## Dataset

Main file: `data/Finance_dashboard_large_dataset.csv` with the columns Transaction_ID, Date, Account_ID, Transaction_Type, Category, Merchant, Amount_INR, Payment_Method, City, Status, Month, Year, Quarter, Weekday.

`category_summary.csv` and `monthly_summary.csv` in the same folder are aggregates generated by the notebook.

## Notebook

`notebooks/Finance_Dashboard.ipynb` cleans the data, builds the monthly and category summaries, and runs 32 analyses grouped into financial overview, spending analysis, transaction analysis, time analysis and detailed analysis. Charts are made with matplotlib. You can run it top to bottom.

## Streamlit dashboard

`app.py` gives everything from the notebook as an app. There are 7 pages - Overview, Spending, Income, Trends, Budget Planner, Transactions and Insights - with sidebar filters for date range, city, account, payment method, category and status. All 32 notebook charts are included, plus some things the notebook doesn't have:

- a budget planner where you set a monthly budget per category and see which ones you go over
- an insights page that writes out findings from the current filter selection
- CSV export of any filtered view

Charts use Altair. The pastel pink theme comes from `.streamlit/config.toml` - delete it if you want the default Streamlit look.

### Running it

```bash
pip install -r requirements.txt
streamlit run app.py
```

Then open http://localhost:8501.

On Windows you can double-click `run_dashboard.bat` instead - it starts the server on port 8501 and opens the browser for you (and just opens the browser if the server is already running). Close the console window to stop the server. `setup_env.bat` creates a `.venv` and installs the dependencies automatically. There is also a `run_dashboard.sh` for Linux/macOS.

The first load reads the whole 250K-row CSV, which takes a few seconds; after that it is cached.

## What I learned

- working with a 250K-row CSV in pandas (groupby, pivot tables, time series)
- keeping a dashboard fast with Streamlit's caching instead of reloading data on every interaction
- translating notebook charts into reusable Altair charts with filters
- what actually matters in personal finance data: monthly net vs savings rate, category concentration, payment method mix
